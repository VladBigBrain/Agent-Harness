# Проверка и откат

## Проверка core

```sh
npm run doctor
ccusage codex daily --offline
rtk git status
rtk git log -5
rtk gain
```

В новой Codex-сессии проверить срабатывание RTK PreToolUse на простой read-only команде. В текущем уже работающем чате обновлённые hooks могут не подхватиться. Не считать установку hook доказательством его срабатывания.

Сопоставлять реальные input/cached/output, число шагов, время и корректность задачи. Не приравнивать `rtk gain` к деньгам или проценту недельной квоты. Не применять изменяющие данные команды ради smoke-теста.

## Отключение RTK

```sh
rtk init -g --codex --uninstall
```

После изменения нужен новый чат/перезапуск. Проверить, что unrelated hooks и глобальные инструкции сохранены. Снимки до активации лежат в ignored `.local/backups/`; указатель последнего — `.local/last-codex-backup`. Если настройки с тех пор менялись, восстанавливать только RTK-блок, не накатывать старый config целиком.

Core-команды — ссылки в `~/.local/bin/`. Удалять их только после проверки, что `readlink` ведёт в этот checkout. Удаление `node_modules/` и `.local/bin/rtk` относится только к этому проекту.

## Возврат старого содержимого репозитория

Тег `archive/pre-token-stack-20261028` указывает на исходный commit до замены. Для просмотра без изменения текущего main:

```sh
git worktree add ../Agent-Harness-old archive/pre-token-stack-20261028
```

Не нужен force push или удаление истории. Все старые файлы доступны через Git.
